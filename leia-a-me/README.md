# Descomplica Direito: Menu Editorial

Extensão local do VS Code que abre uma Webview de navegação em três painéis, inspirada no menu expansivo de [harvard.edu](https://www.harvard.edu/): categorias, itens em foco e conteúdo contextual, com links rápidos fixos na base.

## Executar no VS Code

1. Abra a pasta `vscode-harvard-menu` como pasta do projeto ou mantenha o repositório aberto.
2. Pressione `F5` para iniciar o Extension Development Host.
3. No host, abra a Paleta de Comandos e execute **Descomplica Direito: Abrir Menu**.

A Webview não carrega recursos remotos. Selecionar um recurso exibe uma notificação do VS Code; o botão **Fechar** ou a tecla `Escape` fecha o painel.
